# Inventaire initial — document historique

Ce document ne décrit pas l’état actuel du dépôt. Il s’agissait d’une note de
planification contenant des composants alors envisagés; la présence d’un nom
ou d’un composant dans cette ancienne liste ne prouve pas qu’il existe, qu’il
est terminé ou qu’il a été validé.

Pour l’implémentation actuelle, les limites connues et les validations
automatisées, consulter [Couverture MVP KORAS](mvp-coverage.md) et les sources
du dépôt. Aucun E2E complet sur téléphone ne doit être déduit des tests
unitaires ou widget.
